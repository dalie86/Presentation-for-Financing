# Проверка качества колоды

Проверка идёт в два прохода: сначала автоматический скрипт (дёшево, без скриншотов),
затем визуальный просмотр. Править только то, что найдено; не перестраивать колоду.

## 1. Автоматическая проверка

Запустить скрипт ниже через `use_figma` (только чтение) по всем слайдам раздела.

```js
// INPUT
const ROW_ID = "28:4962";      // раздел колоды
// END INPUT
const PLACEHOLDER = /Заголовок (в одну|в две|карточки|блока|слайда|доклада)|^Заголовок$|Описание (продукта|в одну|в две|: что это)|Утверждение в одну|Пункт списка|Название (шага|части|изменения|\d)|Что происходит на шаге|Подпись (к числу|сверху)|Пояснение( —|:)|Подзаголовок|Короткий подзаголовок|Имя (и фамилия|Фамилия)|^Должность|name\.surname|\+7 900 000|^Дата$|^Тег$|Сноска: пояснение|Параметр \d|^Шаг \d$|^Колонка$|Крупный тезис/;
const row = await figma.getNodeByIdAsync(ROW_ID);
const issues = [];
for (const slide of row.children) {
  const sb = slide.absoluteBoundingBox;
  for (const t of slide.findAllWithCriteria({ types: ['TEXT'] })) {
    if (!t.visible) continue;
    let hidden = false; for (let p = t.parent; p && p !== slide; p = p.parent) if (p.visible === false) hidden = true;
    if (hidden) continue;
    const b = t.absoluteBoundingBox; if (!b) continue;
    const txt = t.characters.trim();
    if (PLACEHOLDER.test(txt)) issues.push({ slide: slide.id, node: t.id, slot: t.name, type: 'placeholder', text: txt.slice(0, 50) });
    // правила из правок авторов (slides-learn/references/edit-patterns.md)
    if (txt.length < 140 && /[^.]\.$/.test(txt) && !/\.\s/.test(txt)) issues.push({ slide: slide.id, node: t.id, slot: t.name, type: 'dotEnd', text: txt.slice(0, 50) });
    if (/\s-\s/.test(txt)) issues.push({ slide: slide.id, node: t.id, slot: t.name, type: 'hyphenDash', text: txt.slice(0, 50) });
    if (txt.length < 40 && /^[а-яё]/.test(txt) && t.fontSize !== figma.mixed && t.fontSize >= 24) issues.push({ slide: slide.id, node: t.id, slot: t.name, type: 'lowercaseLabel', text: txt.slice(0, 50) });
    if (b.x < sb.x - 1 || b.y < sb.y - 1 || b.x + b.width > sb.x + sb.width + 1 || b.y + b.height > sb.y + sb.height + 1)
      issues.push({ slide: slide.id, node: t.id, slot: t.name, type: 'outOfSlide', text: txt.slice(0, 50) });
    for (let p = t.parent; p && p !== slide; p = p.parent) {
      if ('clipsContent' in p && p.clipsContent) {
        const pb = p.absoluteBoundingBox;
        if (pb && (b.x + b.width > pb.x + pb.width + 1 || b.y + b.height > pb.y + pb.height + 1))
          issues.push({ slide: slide.id, node: t.id, slot: t.name, type: 'clipped', by: p.name, text: txt.slice(0, 50) });
        break;
      }
    }
  }
}
for (const slide of row.children) {
  const acc = slide.findAll(n => n.type === 'INSTANCE' && !['Label', 'Header'].includes(n.name) && Object.entries(n.componentProperties).some(([k, v]) => /^(Style|State)$/.test(k) && v.value === 'Accent'));
  if (acc.length > 1) issues.push({ slide: slide.id, type: 'twoAccents', nodes: acc.map(n => n.id) });
}
return { slides: row.children.length, clean: issues.length === 0, issues };
```

Типы находок и что делать:
- `placeholder` — остался текст-подсказка шаблона. Заполнить свойство или слот скриптом C из
  `slides-figma-build`, лишнюю карточку убрать через `count`, свободный текст скрыть `"__hide__"`.
- `twoAccents` — на слайде больше одного элемента `Style`/`State` = Accent. Оставить акцент только
  на кульминации, остальным вернуть обычный вариант скриптом C.
- `dotEnd` — точка в конце однострочного утверждения; `hyphenDash` — дефис вместо тире. Исправить
  скриптом C: авторы правят это почти всегда (на 20 парах: 16 точек в сгенерированных слайдах
  против 7 в финальных, дефисов 3 против 0). Точку оставить в описаниях из полных предложений.
- `lowercaseLabel` — короткая подпись со строчной буквы. Только подсказка: название узла или
  карточки — с заглавной, а пояснение под числом или названием («лет в руководящих ролях») авторы
  оставляют со строчной.
- `clipped` / `outOfSlide` — текст не влез. Сократить по правилам `slides-text-fit` и записать заново. Не уменьшать кегль и не двигать элементы шаблона.

## 2. Визуальный просмотр

Снять скриншоты всех слайдов раздела инструментом `get_screenshot` (по слайду на вызов,
параллельно по 6–7; если ссылка на картинку не открывается — `enableBase64Response: true`,
`maxDimension` 640). Проверить по списку:

1. **История.** Прочитать подряд только заголовки: складываются ли они в связный рассказ, который
   понятен без остального текста? Каждый заголовок — вывод, а не тема («Выручка выросла в 2,4 раза»,
   а не «Выручка»).
2. **Один слайд — одна мысль.** Нет слайдов, где спорят два вывода.
3. **Плотность.** Нет стены текста; на карточках 1–3 строки описания.
4. **Цифры.** Совпадают с данными пользователя, единицы указаны, у графиков есть источник.
5. **Стиль.** Шрифт Navigo, фон Manila/30, цвета только из переменных `Manila Slides`, жёлтый
   акцент максимум на одном элементе слайда (жёлтые кружки с иконками в карточках — не акцент).
6. **Перекрытия.** Текст не спрятан под иллюстрацией. Скрипт этого не ловит: у иллюстраций большие
   габариты, геометрическая проверка даёт ложные срабатывания. Известный случай — `m-value`: линии
   иллюстрации справа заходят под длинные утверждения; тогда сократить текст или сдвинуть картинку.
7. **Иллюстрации и фото.** Иллюстрации уместны по смыслу (менять через Assets → Имиджи /
   Иллюстрация); контакты «Имя и фамилия» заполнены; фото спикера — ручная замена, сообщить.
8. **Ритм.** Нет трёх одинаковых макетов подряд.
9. **Связка рассказа и образа.** По заметкам докладчика (или тексту выступления) и скриншоту
   оценить каждый слайд по правилам `slides-visual-story`: заголовок = вывод речи, у каждой ключевой
   фразы есть якорь, нет элементов-сирот, порядок чтения = порядок рассказа, акцент = кульминация,
   слова и цифры совпадают с речью. Записать оценку (сильная / средняя / слабая); слабые слайды —
   первыми в список правок. Если текста выступления нет — пропустить пункт и сказать об этом.

## 3. Отчёт

Исправить найденное самостоятельно, затем выдать пользователю короткий итог: что проверено,
что исправлено, что нужно сделать вручную (фото, иллюстрации, спорные формулировки), и ссылку
на первый слайд раздела: `https://www.figma.com/slides/<fileKey>?node-id=<id слайда с «-» вместо «:»>`.
