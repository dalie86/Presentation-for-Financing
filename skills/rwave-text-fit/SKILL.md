# Текст под поля макетов

Вход: утверждённый ghost deck (`rwave-storyline`) и исходный материал. Выход: **slide-spec** —
для каждого слайда выбран макет и написан текст каждого поля, уложенный в его вместимость.

## Лимиты

Вместимость поля — из каталога `rwave-template/references/layouts.md` (на этапе плана) и из
инвентаря скрипта B (на этапе сборки). Писать в **85 %** от вместимости. Перенос в Figma идёт по
словам, поэтому длинные слова («клиентоориентированность») съедают остаток строки — заменять их.

Когда текст не влезает, порядок действий:
1. Сократить формулировку (правила ниже).
2. Перенести детали в заметки докладчика.
3. Разделить слайд на два.
4. Взять макет с большим числом полей.
Никогда не уменьшать кегль и не растягивать поля — это ломает шаблон.

## Правила сокращения

1. **Один слот — одна мысль.** Абзац превращается в заголовок карточки (суть, 1–4 слова) +
   описание (как/почему/сколько).
2. **Глагол вместо отглагольного существительного:** «осуществление проверки» → «проверяем».
3. **Убрать пустые слова:** «является», «данный», «в рамках», «с целью», «в настоящее время»,
   «а также», «определённый», «различные».
4. **Цифры цифрами:** «в два с половиной раза» → «в 2,5 раза»; «тысяч рублей» → «тыс. ₽».
5. **Конкретика вместо оценки:** «значительно ускорили» → «ускорили в 3 раза».
6. **Параллельная форма** у пунктов одного слайда: все начинаются с глагола или все — с
   существительного, одной длины ±30 %.
7. **Без точек** в конце заголовков и однострочных пунктов (так в шаблоне). В описаниях из двух
   предложений точку между ними ставить, в конце — нет.
8. **Не повторять заголовок слайда** в карточках.
9. Аббревиатуры раскрывать при первом упоминании прямо на слайде, если аудитория смешанная:
   «Число MR (merge request, запрос на слияние кода)».

Правила, выведенные из правок авторов (`rwave-learn/references/edit-patterns.md`, сила в скобках):
10. **Английский жаргон — простым русским** (4 из 4): «BUY — inner harness, llm gateways» →
    «Готовое — агентный цикл, доступ к моделям»; «BUILD» → «Свое».
11. **Утверждение без пояснения** (5 слайдов): «На начальной стадии — не время считать токены…
    Сначала надо добиться устойчивого результата на сильной модели» → «Сначала результат на сильной
    модели, на основном сценарии». Пояснение — в заметки докладчика.
12. **Не писать связку, которую показывает раскладка** (3 из 3): «Есть два пути» над двумя колонками
    не нужно.
13. **Обобщение без примера рядом** (2 из 2): если на слайде есть общий шаг «Понять вход», строка
    с частным примером «что за расход» лишняя.
14. **Подписи на схемах и в карточках — с заглавной** (4 из 4); **тире, а не дефис** между частями
    фразы (3 из 3).
15. **Критерий — в заголовок колонки, пункты — короткими существительными** (1 случай, но
    совпадает с правилом 1): «Проверить быстро: ошибку видно сразу» + «Письмо клиенту».
16. «ё» или «е» — как в уже готовых слайдах колоды или как скажет автор; по умолчанию «ё».

## Формат slide-spec

Сохранить в рабочую папку `slide-spec.md` — его читает сборщик.

```
## 4. Клиенты уходят из-за срока рассмотрения
layout: cards-3 (11:11341)
fields:
  - title: Клиенты уходят к конкурентам
  - subtitle: Причина — срок рассмотрения   # поле описания схемы; у макетов без него — пропустить
  - card 1 title: 3 дня ожидания
  - card 1 text: Конкуренты дают решение за 15 минут
  - card 2 title: ...
accent: card 1                  # из visual-map: элемент кульминации
notes: |
  - «Конкуренты отвечают за 15 минут» → показать на карточке 1
  - Источник: опрос 1 200 клиентов, сентябрь 2026
```

Если есть `visual-map.md`, текст полей писать **словами из `say`** (правило словесного эха):
сокращать можно, заменять синонимами нельзя. Заметки собирать из `say` в порядке якорей.

Для графика вместо `fields` — `chart:` с типом, подписями, значениями, выделенной точкой и
источником; для схемы — `diagram:` с типом и узлами (см. `rwave-charts`, `rwave-diagrams`).
Поля в `fields` называть по смыслу подсказок макета («card 1 title», «step 3 text») — сборщик
сопоставит их со слотами по инвентарю.

## Самопроверка

- Каждое поле ≤ 85 % вместимости, у многострочных полей нет «висящих» слов-переносов на
  отдельную строку.
- Заголовки контентных слайдов ≤ 37 символов.
- Ни одного поля с текстом-подсказкой шаблона; лишние поля помечены `__hide__` или выбран
  другой макет.
