# Каталог правок авторов: «сгенерировано → ушло в продакшн»

Источник: файл Figma «Обучение модели» (`onK8VwMkqsFdrtlmBYXL3R`, фрейм `1:2`), разобран 3 ноября 2026.
Два блока пар: доклад Андрея Усенко (13 пар, свой шаблон AI native) и доклад Артёма Татаринова
(7 пар, прежний шаблон; два сгенерированных слайда автор слил в один). Всего 20 пар.

Каждая правка отнесена к одному из трёх классов:
- **ремесло** — модель могла сделать так сама; из этого выводятся правила;
- **содержание** — автор добавил новые факты, цифры, термины; учить на этом нельзя, но можно
  заранее спрашивать;
- **вкус** — решение конкретного автора или колоды; применять, только если автор подтвердил.

Сила правила — в скольких парах из тех, где ситуация встретилась, автор сделал именно так.

| H4 | Цифры, которые уже есть на графике, не обязательно дублировать в заголовке; заголовок называет предмет, подзаголовок — роль | вкус | 1 из 2 графиков | «Atomic: с 44% до 81% задач» → «Atomic – харнесс для разработки» + «PE ставит задачу и принимает результат, код пишет только Atomic» |

**Уточнение к правилу «заголовок = вывод»** (навыки `slides-storyline`, `slides-visual-story`):
вывод остаётся обязательным, но живёт в паре «короткий заголовок + подзаголовок». Если у макета
нет поля подзаголовка, вывод уходит в описание схемы или первую строку контента.

## 4. Содержание (не учить — спрашивать)

Правки, которые модель сделать не могла: обновлённые цифры («138 из 171» → «292 из 360»; появилось
«15 кредитных экспертов в эксперименте»), новые термины команды («Product Engineer», «Human review»),
новые примеры («Score уверенности OCR моделей»), новая фраза в постановке задачи.

Вывод для процесса: в брифе спросить, **на какую дату должны быть цифры** и какие термины принято
употреблять в команде; перед сборкой показать автору список всех чисел колоды на сверку.

## 5. Слайды, принятые почти без правок текста

«Внедряем инструмент или меняем метрику потока?», «Четыре решения руководителя», «Спецификация
снимает неопределённость…», «Постановка тоже идёт через систему» (добавлена одна фраза). Общее: один
заголовок в одну-две строки, параллельные пункты, нет жаргона. Вёрстку правили на всех 20 слайдах.

Базовая линия для оценки: **4 из 20 слайдов** приняты почти без правок текста, **0 из 20** — без
правок вёрстки.
