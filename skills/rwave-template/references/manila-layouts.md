# Шаблон «Манила 30» (Financing)

Файл: `https://www.figma.com/slides/Va5dPaSmSmwC228TKjiaGE` (fileKey `Va5dPaSmSmwC228TKjiaGE`).
Источники стиля: «Демо Financing» (слайды ценности на Manila/30) и Manila-варианты шаблона CIB
(титулы, перебивки, Q&A, финал). Все слайды 1920×1080, фон — переменная `bg/base` (Manila/30).

Слайд собран из инстансов, а не из нарисованных слоёв. Тексты меняются через **свойства
компонентов** (`instance.setProperties`), а не через `characters` вложенных слоёв: так правка не
ломает связь с компонентом. Свойства называются по-русски, ключ ищется по префиксу до `#`.

## Токены

Коллекция переменных **Manila Slides** (алиасы на брендовые примитивы `[Brand] Primitives Colors`
и `Vienna WDS Primitives`; при обновлении библиотеки цвета обновятся сами).

| Токен | Примитив | Где |
|---|---|---|
| `bg/base` | Manila/30 #CDEBEB | фон контентных слайдов |
| `bg/deep` | Manila/60 #A5D6D6 | титул (полоса), перебивка, Q&A, плашка финала |
| `bg/soft` | Manila/10 | редкий спокойный фон |
| `surface/card` | Riga/01 #F9F9FA | карточки, ячейки таблиц |
| `surface/card-soft` | Manila/05 | «было», второстепенная карточка |
| `surface/accent` | Rio/30 #FEE600 | **один** акцент на слайд |
| `surface/accent-soft` | Rio/05 | колонка вывода в таблице |
| `surface/tag` | Manila/100 #5ABEBE | теги |
| `line/divider`, `line/connector` | Manila/120 #36A0A6 | разделители, стрелки |
| `text/primary` / `secondary` / `muted` | Riga/200 / 160 / 100 | текст |
| `chart/primary` / `secondary` / `muted` / `accent` | Manila/120 / 80 / 60, Rio/30 | графики |

Числа: `space/margin` 40, `space/gap` 24, `space/card-pad` 40, `radius/card` 32, `radius/tag` 40.

Текстовые стили `Manila/*` (Navigo Regular, кроме Body Bold): Display 120/120, Title 72/80,
Title S 56/64, Statement 48/52, Card title 40/52, Body 32/40, Body Bold 32/40, Caption L 28/36,
Description 24/30, Caption 18/24, Number XL 200, Number 120, Number S 72.

## Компоненты (раздел `00 · Компоненты`)

| Компонент | Свойства | Назначение |
|---|---|---|
| `Tag` | Текст; Style = Manila / Accent / White | теги продукта, срока, ЦА, статуса; облако тегов |
| `Divider` | Color = Manila / Dark | линия между строками ценности и колонками |
| `Step marker` | Номер; State = Default / Accent / Manila | кружок с номером |
| `Bullet`, `Arrow` | — | маркер списка; стрелка потока (96×24) |
| `Footnote`, `Source` | Текст | сноска 24 px; источник 18 px |
| `Part number` | Номер | «01» на перебивке |
| `Card / Horizontal` | Заголовок, Описание, Иконка (bool); Style = White / Accent / Soft | длинная строка-карточка 1760 |
| `Card / Vertical` | то же | карточка в сетке; ширину задаёт родитель (FILL) |
| `Number card` | Число, Подпись; Style = White / Accent / Clear | крупное число 120 px |
| `Value row` | Утверждение, Подпись | строка «Проблема клиента / Решение / Метрика» |
| `Step` | Название, Описание; State = Default / Accent | шаг процесса (маркер внутри: свойство «Номер») |
| `List item` | Текст | пункт списка |
| `Table cell` | Значение; Type = Header / Body / Total / Highlight | ячейка; строка таблицы = горизонтальный auto layout из ячеек |
| `Bar row` | Подпись, Значение; State = Default / Accent | полоса графика. Длину полосы в инстансе изменить нельзя — инстанс отсоединить (`detachInstance`) и задать ширину `bar` |
| `Contact` | Имя, Должность, Почта, Телефон | контакты на финале |

Из библиотеки «Базовый шаблон презентаций»: `Header` (Type = Title / Title Tiny / Content /
Content Preheader / Header + description; булевы `Tag 1`, `Tag 2` — **выключать**), `Label`
(иконки в жёлтом круге), `logo`, иллюстрации `Имиджи / Иллюстрация / Полоса / *` (1980×500, для
титула) и `Квадрат / *` (1000×1000). У иллюстрации скрывать слой `фон` и убирать заливку
инстанса — тогда она лежит на Manila без цветной плашки.

## Правила стиля

1. Один жёлтый элемент на слайд.
2. Карточки — белые на Manila/30; «было» и второстепенное — Soft.
3. Фон `bg/deep` — только у титула-полосы, перебивок, Q&A и плашки финала.
4. Шапка — библиотечный `Header`; заголовок слайда 72 px, 1–2 строки.
5. Не рисовать новые цвета: всё через переменные `Manila Slides`.
