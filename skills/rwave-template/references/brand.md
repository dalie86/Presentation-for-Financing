# Фирменный стиль R'WAVE (извлечён из шаблона)

## Шрифт

- **Navigo Regular** — весь текст шаблона (заголовки, тело, подписи). Navigo Light встречается редко.
- Кегли шаблона: 220 (крупное слово, цифры перебивок), 176 (служебные указатели), 114 (заголовки
  титулов и перебивок), 72 (заголовок контентного слайда), 56, 48 (заголовки карточек), 32 (основной
  текст), 24 (пояснения, сноски, подписи графиков).
- Шрифт должен быть доступен в аккаунте Figma. Если `loadFontAsync` для Navigo падает — остановиться и
  сообщить пользователю: колоду без фирменного шрифта не собирать и Inter не подставлять.

## Цвета

| Роль | HEX | Где встречается |
|---|---|---|
| Основной текст | `#2B2D33` | Почти весь текст |
| Второстепенный текст | `#808185` | Подписи, даты, оси графиков |
| Жёлтый акцент R'WAVE | `#FEE600` | Логотип, акцентная карточка, выделенное значение на графике |
| Лаванда насыщенная | `#BDAFEC` | Фон титулов, основная серия графиков |
| Лаванда светлая | `#E3DCFA`, `#EBE7FC`, `#F8F5FF` | Фоны карточек на акцентном фоне |
| Зелёный средний | `#80C280` | Вторая серия графиков, иллюстрации |
| Зелёный насыщенный | `#609960`, `#4C7D4C` | Третья серия, линии иллюстраций |
| Зелёный светлый | `#D3EBD3`, `#E6F3E6` | Фоны зелёных вариантов макетов |
| Серый фон карточек | `#F4F4F4` | Карточки на сером фоне |
| Сетка графиков | `#E4E4E6` | Линии сетки |

## Правила

1. Жёлтый — только для одного главного элемента на слайде (акцентная карточка, ключевой столбец).
   Два жёлтых элемента на слайде — ошибка.
2. Цвета серий графиков по порядку: `#BDAFEC`, `#80C280`, `#609960`, `#E3DCFA`, `#4C7D4C`.
3. Не менять цвета, кегли и расположение элементов клонированных макетов. Всё оформление уже
   в шаблоне; агент меняет только текст.
4. Числа: десятичная запятая («2,4»), пробел перед единицей («2,4 млрд ₽», «45 %» допустимо
   без пробела — как в шаблоне «30%»), тире в диапазонах «2022–2025».
5. Логотип и знак R'WAVE в шапке не трогать.
