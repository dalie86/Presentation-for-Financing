# Разобранные слайды

Примеры из колод, собранных плагином. Используются как образец карточки и как калибровка оценки.

## Сильная связка

### «Агент решает 80%, а смотрим всё»
- job: проследить → увидеть застревание
- form: `flow` из 5 узлов + обратная стрелка «Улучшение → Харнесс»
- say → anchors: «агент решает 80%» → узел «Харнесс»; «каждый пятый с ошибкой» → «Результат»;
  «я всё равно его смотрю» → «Оценка» **[accent]**; «и снова по кругу» → обратная стрелка с подписью
- Почему сильная: каждая фраза указывает на узел, порядок узлов = порядок речи, жёлтый — на
  кульминации, подпись под стрелкой повторяет вопрос спикера.

### «MR до merge: в 3 раза быстрее»
- job: заметить изменение
- form: `bar`, три периода, акцент на последнем
- say → anchors: «было 8,6 часа» → полоса августа; «стало 2,9» → полоса октября **[accent]**;
  «при растущем потоке» → подписи числа задач справа; «это не время ручного review» → подпись источника
- Почему сильная: цифра заголовка (в 3 раза) читается из двух крайних полос; оговорка спикера стоит
  на слайде, поэтому вопрос из зала о методике закрыт заранее.

## Средняя связка

### «Не описывать всё — найти зону доверия»
- job: увидеть развилку
- form: `scheme-2` «Автоматический ход / Передать человеку»
- Нарушение: пункты колонок не параллельны («Эксперт и инженер задают границу» ↔ «Спорные случаи
  не держат автомат»), а в речи главная мысль — «эксперт определяет, каким платежам дать
  автоматический ход», то есть сама граница. Граница на слайде не нарисована, только две стороны.
- Правка: в описании схемы назвать критерий границы словами спикера; пункты колонок сделать
  парными (что идёт / почему; что идёт / почему).

## Слабая связка

### «Пилот есть. Как масштабировать?»
- job: переключиться (три вопроса залу)
- form: `theses-3` с иллюстрацией ракушки
- Нарушения: иллюстрация не связана со смыслом (сирота, спорит с темой); вопросы равного веса, а
  спикер выделяет третий («и главное — доверять или проверять»), акцента нет.
- Правка: макет без иллюстрации с акцентом на третьем пункте (`scheme-3-accent` с акцентом в
  центре — переставить главный вопрос в центр) или `divider-banner` с главным вопросом крупно и
  двумя другими в пояснении.

### «Work OS» (три крупных числа)
- job по речи: проследить устройство (агент, MCP, DataLake, skills) + запомнить число
- form: `big-numbers`
- Нарушение: спикер две трети времени рассказывает про устройство эксперимента, а на слайде только
  числа; два `job` на одном слайде.
- Правка: начинать с устройства (следующий слайд «Интерфейсы человека — агенту»), затем числа —
  или сказать про устройство на следующем слайде и оставить на этом только числа.
