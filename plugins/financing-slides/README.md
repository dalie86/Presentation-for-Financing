# financing-slides — презентации в Figma Slides под ключ (Claude и Codex)

Один плагин для Claude и Codex: 10 навыков, подключение к Figma и (в Claude) 3 агента. Вы приносите тезисы, текст
выступления и цифры. Claude выстраивает историю, связывает рассказ с картинкой на каждом слайде,
сжимает текст под макеты, собирает слайды в Figma Slides, рисует графики и схемы и сам проверяет
результат.

## Шаблон

«Манила 30» — шаблон Financing: https://www.figma.com/slides/Va5dPaSmSmwC228TKjiaGE.
35 макетов в 10 разделах (титулы, перебивки, слайд ценности, карточки, числа, списки, таблицы,
шаги и схемы, графики, финал) плюс холсты под графики, 17 компонентов, переменные `Manila Slides`
и стили `Manila/*`. Для новой колоды сделайте копию файла и дайте Claude ссылку на неё.

## Установка в Claude (один раз)

1. Скачайте файл `financing-slides.plugin` и добавьте его в Claude как плагин (откройте карточку
   файла в чате и сохраните плагин в аккаунт либо загрузите файл в разделе плагинов).
   В Claude Code вместо файла можно поставить из репозитория:
   ```
   /plugin marketplace add dalie86/Presentation-for-Financing
   /plugin install financing-slides --marketplace dalie86/Presentation-for-Financing
   ```
2. Подключите коннектор **Figma** в настройках Claude и войдите в свой аккаунт Figma.
3. Проверка: напишите `/slides-deck` — Claude должен спросить про бриф или попросить материал.

## Установка в Codex (один раз)

Нужен доступ к приватному репозиторию `dalie86/Presentation-for-Financing` на GitHub.

1. Добавьте каталог плагинов из репозитория:
   ```
   codex plugin marketplace add dalie86/Presentation-for-Financing
   ```
2. В приложении Codex откройте **Plugins**, выберите каталог **Financing** и установите
   **Financing Slides**. При установке Codex попросит войти в Figma — разрешите доступ.
3. Если работаете только в терминале и Figma ещё не подключена:
   ```
   codex mcp add figma --url https://mcp.figma.com/mcp
   ```
   и войдите в Figma, когда Codex попросит (`codex mcp login figma`, если окно входа не открылось).
4. Проверка: напишите `$slides-deck` или `/skills` → `slides-deck`.

Без каталога плагинов навыки можно поставить и вручную: скопируйте папки из `skills/` в
`~/.agents/skills/` и подключите Figma командой из шага 3. Перезапустите Codex.

В Codex нет агентов плагина (`story-editor`, `slide-builder`, `deck-reviewer`): Codex проходит те же
этапы сам. Официальный плагин Figma для Codex можно держать рядом — он добавляет навыки `figma-use`
и `figma-use-slides`, которые наши скрипты и так подгружают через Figma MCP.

Если у вас стоит прежний плагин `rwave-slides` или отдельные навыки `rwave-*` — удалите их: этот
плагин их полностью заменяет, а старые инструкции собирают слайды в другом шаблоне.

## Что нужно в Figma

- Платный план (Professional и выше), место **Full**.
- Своя копия шаблона https://www.figma.com/slides/Va5dPaSmSmwC228TKjiaGE с правом редактирования
  и доступ к библиотеке «Базовый шаблон презентаций» (шапки, логотип, иллюстрации).
- Шрифт **Navigo** в вашем аккаунте Figma.

## Как пользоваться

```
/slides-deck Доклад на конференцию, 20 минут, 16–20 слайдов. Собери в разделе «Иван».
Вот сторилайн, текст выступления и цифры (приложите md, txt, xlsx или старую pptx).
```

1. Claude задаст до трёх вопросов и покажет структуру — список заголовков-выводов. Правьте логику
   здесь: это быстро.
2. Для выступления вживую Claude составит карту связки: что видит зал на каждом слайде и к какому
   элементу привязана каждая ваша фраза.
3. После вашего «ок» соберёт слайды в Figma — в новом разделе или в разделе, который вы назвали.
4. Проверит каждый слайд, даст ссылку на первый слайд и список ручных доработок (фото спикера,
   мемы, иллюстрации). Заметки докладчика — по тексту выступления.

После показа пришлите ссылку на финальную версию и скажите «научись на правках» — плагин выведет
новые правила. Правки потом — обычными словами: «на 5-м слайде сократи описание», «замени график на линию»,
«проверь, совпадает ли рассказ со слайдами».

## Что внутри

| Навык | Что делает |
|---|---|
| `/slides-deck` | Полный цикл: бриф → история → связка → план → сборка в Figma → проверка |
| `slides-storyline` | История по пирамиде Минто: главная мысль, SCQA, заголовки-выводы |
| `slides-visual-story` | Связка рассказа и образа: что зал видит на слайде, к какому элементу привязана каждая фраза, где акцент. Оценка связки готовой колоды |
| `slides-text-fit` | Сжатие текста под вместимость полей словами спикера, `slide-spec.md` |
| `slides-template` | Каталог 35 макетов «Манила 30», компоненты и их свойства, токены цвета, шрифт |
| `slides-figma-build` | Проверенные скрипты сборки: клон → инвентарь → заполнение свойств и числа карточек, заметки |
| `slides-charts` | Графики (столбцы, полосы, линии, кольцо, доля с объёмом) нативными векторами в цветах шаблона |
| `slides-diagrams` | Схемы: сначала готовые макеты, иначе поток / матрица / хаб / механизм и числа |
| `slides-qa` | Проверка: остатки подсказок, обрезанный текст, история, стиль, связка с рассказом |
| `slides-learn` | Обучение на правках авторов: сравнивает сгенерированные и финальные слайды, выводит правила, обновляет навыки, меряет долю слайдов без правок |

Агенты: `story-editor` (история, связка и план, без Figma), `slide-builder` (сборка в Figma),
`deck-reviewer` (независимая проверка — не видел, как собиралась колода).

## Ограничения

- Запись в Figma через MCP — бета-функция Figma; лимит около 200 вызовов в день на место. Колода на
  15–20 слайдов тратит 25–40 вызовов.
- Фото, мемы и иллюстрации агент на слайд не вставляет: ставит подписанную рамку и отдаёт картинку
  файлом — перетащите её в рамку.
- Графики и схемы — редактируемые фигуры, но не связаны с данными: при новых цифрах попросите
  перерисовать.
- Длину полос в макете `m-bars` в инстансе не поменять — агент отсоединяет их или рисует график
  скриптом на холсте.
- Готовую колоду можно выгрузить из Figma Slides в PowerPoint; клики и анимации после выгрузки
  проверьте вручную.

## Обновление шаблона

Если дизайнер добавит или изменит макеты, попросите Claude «пересними карту макетов шаблона» —
он прочитает файл скриптом B и обновит `skills/slides-template/references/layouts.md`.
